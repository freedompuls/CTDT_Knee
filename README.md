# CTDT_Knee
This repository contains the official implementation of our paper on automated Kellgren–Lawrence (KL) grading of knee osteoarthritis from plain radiographs. The core idea is to exploit the measured error complementarity between a modern CNN and a deformable-attention Transformer, rather than simply enlarging model capacity.
Method. We first quantify the hard-example overlap between ConvNeXt-Tiny and DAT-Tiny; their intersection covers only 3.5% of the union, indicating that the same image rarely challenges both architectures. Based on this observation, we concatenate the two 768-dimensional branch features and train a learnable linear fusion layer. Training follows a two-stage progressive schedule: (1) freeze both backbones and train only the fusion layer, then (2) unfreeze the last two stages of each backbone for joint fine-tuning at a lower learning rate. To address residual weaknesses, we mine hard examples that are misclassified over consecutive epochs and apply targeted moving least squares (MLS) geometric deformation—distortion and stretching—to their union. Augmented copies are added only to the training set.

Data and results. Experiments use the public OAI-based Knee Osteoarthritis Severity Grading Dataset (5,778 training, 826 validation, 1,656 test images). The proposed method reaches 74.88% overall test accuracy (95% CI 72.73–76.91%), outperforming six self-trained baselines and published single-model results, with 86.5% of errors confined to adjacent KL grades. Ablation shows that two-stage training contributes +0.79 percentage points and MLS targeted augmentation a further +1.45.

Repository contents. The code includes dataset preparation, ConvNeXt/DAT training, hard-example statistics, two-stage stacking ensemble training, MLS augmentation, evaluation (accuracy, macro precision/recall/F1, QWK, MAE, confusion matrix), and Grad-CAM/t-SNE visualization. Configuration files reproduce the reported hyperparameters and data splits. Install dependencies via pip install -r requirements.txt; run python train_stage1.py, python mine_hard_examples.py, and python train_stage2.py sequentially. Evaluation is performed with python evaluate.py --split test. All figures in the paper are original and generated by the provided scripts.
